# Usage Instructions

An error code is presented as 12 characters. Taking the error code MIE03E000001 as an example, the meaning and description of each segment are shown in [Table 1](#table1121312172367).

**Table 1**<a name="table1121312172367"></a> Description of Each Error Code Segment

|Error Code Field|Meaning|Description|
|--|--| --|
|MIE|Product name (3 characters)|Abbreviation of MindIE|
|03|Component (2 characters)|Component code. The component codes are as follows:<ul><li>03: MindIE Motor</li><li>05: MindIE LLM</li><li>06: MindIE SD</li></ul>|
|E|Level (1 character)|Error|
|000001|Error code (6 characters)|Internal hexadecimal error code of the component|
