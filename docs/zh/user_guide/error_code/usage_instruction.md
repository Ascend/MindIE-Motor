# 使用说明

错误码以12位字符形式体现，以MIE03E000001错误码为例，各段含义及说明如[表1](#table1121312172367)所示。

**表 1**<a name="table1121312172367"></a> 错误码各段说明

|错误码字段|含义|说明|
|--|--| --|
|MIE|产品名称（3位）|MindIE的缩写|
|03|组件（2位）|组件编码，各组件编码如下：<ul><li>03：表示MindIE Motor组件</li><li>05：表示MindIE LLM组件</li><li>06：表示MindIE SD组件</li></ul>|
|E|级别（1位）|Error|
|000001|错误码（6位）|为组件内部16进制错误码|
